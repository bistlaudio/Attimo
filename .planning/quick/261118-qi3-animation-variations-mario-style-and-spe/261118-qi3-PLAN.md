<objective>
Mario-style animation variations and the Spell hand clips for the Mannequin (Rig_Medium), built on the generic retarget pipeline of the sibling quick task 261118-qbt (`attimo/tools/clip_retargeter.gd` with the `ual` family, `attimo/tools/conform_external_clip.gd`, the `RETARGETED` table in `attimo/tools/build_animation_library.gd`).

Purpose: the movement already feels right; the presentation should now vary (idle breaks, sprint momentum, distinct Jump 2 and long jump, soft/hard/roll landings) and the hand should read as a spell hand (raise, hold, shoot, lower) instead of a pistol aim, without ever delaying control.
Output: UAL clips conformed and retargeted into the library under a quality gate, a reusable VariantPicker, a regenerated AnimationTree, animator wiring, tests, updated docs/ANIMATION-MAP.md.

User-approved clip design (from the planning context, treated as locked): aim press `Spell_Simple_Enter`, aim held `Spell_Simple_Idle_Loop` (replaces `Ranged_1H_Aiming`), `use_hand` press `Spell_Simple_Shoot` as an upper-body OneShot, aim release `Spell_Simple_Exit`; `Push_Loop` imported for Phase 5, not wired. Idle `Idle_A` with random 5-8 s breaks from {`Idle_B`, UAL `Idle_Loop`}, any input cancels. Run `Running_A`, above run speed blend to UAL `Sprint_Loop`, no sprint button. Jump 1 as now, Jump 2 a visibly different take, Jump 3 the existing pirouette, long jump KayKit `Jump_Full_Long` cut without wind-up. Landing soft KayKit `Jump_Land`, hard UAL `Jump_Land`, fast horizontal UAL `Roll` (presentation only, D-08). Hit {`Hit_A`, `Hit_B`, UAL `Hit_Chest`, UAL `Hit_Head`}, death {`Death_A`, `Death_B`, UAL `Death01`}, interact {KayKit `Interact`, UAL `Interact`}, random without immediate repeat, library and picker only until Phase 4/6 gives them a state. Rules kept: animation changes on the same frame as the state, anticipation at most 2 frames, no landing lock. The UAL clips are external retargeted clips under qbt's deviation DEV-04 (FOUND-05 "kit clips only"); cite DEV-04 in the docs.

Discretion choices made here (document them in docs/ANIMATION-MAP.md):
- Jump 2 uses KayKit `Jump_Full_Short` (native rig, no retarget risk). UAL `Jump_Start` is the documented alternative if the gym check finds Jump 2 not visibly different.
- Landing priority: roll (horizontal speed) before hard (impact speed) before soft; soft fires only into Idle (as today), roll and hard may also fire into Run.
- Idle-break cancel set: every gameplay action (move_*, jump, dash, aim, use_hand, interact) and any FSM state change. Camera look does not cancel a break.
- No pose hold for the long jump: LongJump -> Fall still switches to `Jump_Idle` on the apex frame (a hold would be a new deviation from the same-frame rule; DEV-02 stays the only hold).
- The Shoot OneShot shows only while aiming (outside aim the layer weight is 0); hip-fire presentation is Phase 4.
- The new tunables go into MovementConfig (live F2 tuning like air_dash_hold_time); docs/MOVEMENT-METRICS.md is regenerated because its config snapshot lists every MovementConfig float.
</objective>
