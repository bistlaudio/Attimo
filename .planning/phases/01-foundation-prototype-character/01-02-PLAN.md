**As a** developer, **I want to** see the KayKit Mannequin animate on input in a Prototype Bits test scene, **so that** the project base and the prototype pipeline are proven.

This plan is an expansion slice. It puts the Mannequin onto the tracer's `VisualRoot` and drives it from the existing FSM, so Space now shows a visible jump instead of only a fact.
