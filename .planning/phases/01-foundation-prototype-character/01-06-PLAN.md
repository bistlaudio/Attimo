- In _ready, loop over EventBus.get_script().get_script_signal_list() with a typed loop variable. For each entry, connect EventBus to _on_fact bound with the signal name, then set visible = false.

- Root CanvasLayer named EventLog, layer 100, with the script.
- Child PanelContainer anchored top-left with a 12 px margin and custom_minimum_size x 520. A StyleBoxFlat sub-resource sets the background to black at 0.6 alpha.
- Inside it, a RichTextLabel named Lines with unique_name_in_owner true, fit_content true, scroll_following true and bbcode off.
