## Phase Goal

**As a** developer, **I want to** see the KayKit Mannequin animate on input in a Prototype Bits test scene, **so that** the project base and the prototype pipeline are proven.

This plan is an expansion slice. It delivers the greybox building blocks that plan 01-07 places into the test scene: a floor to stand on, walls to stop the player, and reference blocks on the 1 m grid.

<objective>
Copy the four Prototype Bits pieces the test scene needs and wrap each one in a StaticBody3D scene with a box collision shape that matches its mesh. Prove the collision with a smoke test that also drops the Player onto a floor tile.

Purpose: FOUND-05 says all greybox geometry comes from Prototype Bits, and KayKit glTFs ship without collision. Explicit wrapper scenes keep layer and shape choices visible in the diff (RESEARCH Pattern 10).
Output: 9 copied asset files (+ import sidecars), 4 wrapper scenes, 1 smoke test.
</objective>
