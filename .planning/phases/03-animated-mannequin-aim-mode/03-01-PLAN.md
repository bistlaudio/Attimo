## Phase Goal

**As a** player, **I want to** have the Mannequin animate with every move and blend into an aim mode, **so that** movement reads clearly and I can aim.

This plan replaces the flat animation state machine with the BlendTree backbone every later plan plugs into (TimeScale, Land overlay, later Aim), removes the landing lock, and ends with the decision checkpoint that settles the open defaults before wave 2.

<objective>
Generate a BlendTree animation root with a tool, switch the Mannequin and the animator to it, migrate every test that reads the old parameter paths, add a timing guard for same-frame response, landing without lock and the 2-frame anticipation limit, and stop for the developer to confirm the defaults the later plans build on.

Purpose: MOVE-09 and ROADMAP criterion 4. The old root (a state machine with a Land state and an at-end edge) locks the crouch for up to 29 frames after a move input; every later layer (TimeScale, Aim, strafe points) needs a BlendTree root.
Output: tools/build_mannequin_tree.gd, scenes/player/mannequin_tree.tres, rewritten MannequinAnimator, fixture helpers, migrated tests, new test_animation_timing, the decision record in 03-01-SUMMARY.md.
</objective>
