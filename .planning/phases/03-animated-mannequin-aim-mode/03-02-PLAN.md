**As a** player, **I want to** have the Mannequin animate with every move and blend into an aim mode, **so that** movement reads clearly and I can aim.

This plan brings every kit clip the phase needs into the one animation library (MOVE-09: kit clips only) and removes the Dodge root drift at the source.

Output: copied GLB + .import, regenerated rig_medium_library.res (13 clips), updated whitelist (33), ORIGINALS, library test, CONVENTIONS line.
</objective>
