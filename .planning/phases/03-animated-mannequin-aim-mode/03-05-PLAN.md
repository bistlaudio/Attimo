## Phase Goal

**As a** player, **I want to** have the Mannequin animate with every move and blend into an aim mode, **so that** movement reads clearly and I can aim.

This plan adds the crosshair that marks where the aim points while the button is held, and puts it into both play scenes.

<objective>
Build a code-drawn crosshair (dot plus thin ring, reserved lock state) shown only while aiming, and instance it in the movement gym builder and the test scene.
