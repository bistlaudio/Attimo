# Phase 05.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Source: 05.1-RESEARCH.md "Validation Architecture".

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Project smoke harness `attimo/tests/run_smoke.gd` (auto-discovers `res://tests/smoke/test_*.gd`), helpers in `attimo/tests/fixtures.gd` |
| **Config file** | none (`attimo/project.godot`) |
| **Quick run command** | `bash attimo/tests/run.sh <test_a>,<test_b>` (substring filters) |
| **Full suite command** | `bash attimo/tests/run.sh` |
| **Estimated runtime** | ~20-40 s filtered, ~6-9 min full (baseline 73 files, 3572 checks, 0 failed) |

Note: `timeout` is not installed on this Mac; a `run.sh --tool` script with a script error can hang. Watch tool runs.

---

## Sampling Rate

- **After every task commit:** filtered run of that task's test files
- **After every plan wave:** full suite
- **Before `/gsd:verify-work`:** full suite green, gym regenerated via `build_movement_gym`
- **Max feedback latency:** ~40 s per task
