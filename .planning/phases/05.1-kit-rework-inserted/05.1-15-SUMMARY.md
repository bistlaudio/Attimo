## Deviations from Plan

**1. [Rule 1 - Bug in plan values] Leaf storm accel 74, not 20**
- The plan said accel 20. The run state restores the run velocity at ground_accel 70 per second after the push is applied, so a push of 20 changes nothing (and idle decel is 55). A gust below that rate is invisible.
- Fix: accel 74, which nets about 4 m/s2 against a running player (clearly slowed, never reversed) and pushes a standing or airborne player outright. test_force_volume pins both ("gust slows below run speed - 1.5, never below 0.5, recovers between gusts"). The value is an F2 start value; the config doc comment states the rule.

**2. [Rule 1 - Stale assertion] test_look_pass minimum scene count 18 -> 15**
- Deleting the nozzle, geyser and wind tunnel scenes removed three entries from scenes/mechanisms; the look pass now covers them as kit presets. Count assertion lowered, no design value changed.

**3. Station slots**
- Plan said stations 6 m apart; slots are 12 m, so the three steam stations take one slot each (north row 1, columns 0..2) and the two nature stations columns 0..1.

**4. Steam stream volume 4 x 4 x 10 m** (old tunnel 6 x 6 x 16) to fit a 12 m slot; strength and accel are the old tunnel's.
