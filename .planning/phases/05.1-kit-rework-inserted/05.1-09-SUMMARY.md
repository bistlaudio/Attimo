# Phase 05.1 Plan 09: Clock HUD, refusal cue and wall-run lean Summary

The HUD now shows the arm energy as a clock of 12 whole steps with an hour hand and a second hand, every refusal shakes and flashes it red with an empty klack, and the wall run leans the head away from the wall with the feet toward it.

## Tasks

1. HUD tests rewritten (clock, refusal), wall tests inverted (lean away, head farther than hips, pivot offset, plain/steam parity). Committed together with their implementations (see Deviations).
2. Clock face in `energy_hud.gd`, soft income tick in `energy_fx.gd`: commit eff1303.
3. Wall-run lean flip, `wall_run_feet_offset`, head clamp removed: commit 799897c; metrics regenerated: separate docs commit.

## Key results

- `EnergyHud`: `hand_angle_for`, `displayed_angle`, `hand_at_rest`, `second_hand_visible`, `second_hand_angle`, `refusal_time_left`, `shake_offset`, `flash_amount`, `clock_rect`. `chambers_rect`, `_draw_chamber` and `chamber_fill` are gone; Moto badge, module plate, speed gauge and health slot stay.
- Hand animation: klack back about 0.12 s with an ease-out-back overshoot, tick forward 0.15 s; a new target restarts from the displayed angle and the hand always ends on a whole step.
- Refusal: 0.35 s decaying sine shake, 0.25 s red lerp of fill and rim, `PlaceholderTone` klack; one timer each, restarted not stacked (T-05.1-26).
- Arm cores already read `core_fill` thirds and flickered on `energy_refused` (rate limited); no code change needed there.
- Wall run: lean axis `up x wall_normal`, full `wall_run_lean_deg` (18, measured error 0.00 degrees), head 0.21 m farther from the wall than the hips, Mannequin pivot 0.35 m toward the wall (error 0.000 m), CharacterBody3D position untouched (T-05.1-27). `WALL_RUN_HEAD_CLEARANCE`, `wall_run_lean_limit_deg`, `_measure_head_clearance` removed; `Fixtures.head_to_wall_distance` became `bone_to_wall_distance(bone_name)`.
- MOVEMENT-METRICS: only the new config row and latency noise changed.
