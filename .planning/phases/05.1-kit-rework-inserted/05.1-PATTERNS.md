## Pattern Assignments

### `scripts/kit/blocks/<new_block>.gd` (block, event-driven) - the template for force_volume, impulse, reaction_to_load, trigger

**Analog:** `scripts/kit/blocks/wall_surface.gd` (smallest, always-on) and `scripts/kit/blocks/catch_launch.gd` (phase machine, request API).

**Header + class pattern** (`wall_surface.gd:1-30`, `catch_launch.gd:1-3`): `class_name X` + `extends KitBlock`, long `##` doc comment naming plan, decision ids, threat ids; constants first; `@export var config: XConfig`.

**Config duplication, collision setup in `_ready`** (`catch_launch.gd:52-62`; `wall_surface.gd:38-45`):
```gdscript
func _ready() -> void:
	if config == null:
		config = CatchLaunchConfig.new()
	config = own_config(config) as CatchLaunchConfig      # D-12: never write the shared .tres
	_trigger.collision_layer = 0
	_trigger.collision_mask = PhysicsLayers.PLAYER
	...
	_trigger.body_entered.connect(_on_body_entered)
```

**Player is touched only through request APIs, deferred from overlap callbacks** (`catch_launch.gd:196-206`, `bounce_pad.gd:62-69`):
```gdscript
func _on_body_entered(body: Node3D) -> void:
	var player: PlayerController = body as PlayerController
	if player == null or _phase != Phase.ARMED or player.loader_active():
		return
	...
	player.call_deferred(&"catch_into_loader", profile)
```
For a continuous volume use `player.push_toward(dir, speed, accel)` each `_physics_process` as in `mechanisms/force_field.gd:50-75`. Never write `.move_velocity` / `.vertical_speed` / `.velocity =` (`test_kit_blocks.gd` `FORBIDDEN_WRITES` greps the script source).

**Phase machine** (`catch_launch.gd:131-143`): `enum Phase { ARMED, CAPTURING, COOLDOWN }`, `_timer`, `reset()` override calling `super.reset()` and restoring runtime state (FallReset sweep).

**Profile enum, no flag soup (D-11):** one enum in the config (`TimedMotionConfig.Profile { SWEEP, TILT }`, `CatchLaunchConfig.Profile { FREE_AIM, FIXED }`), `match`/`if` on it in the block.

**Income hook (D-43):** add to `KitBlock` (`kit_block.gd`) one `grant_step(player)` with a per-node cooldown, calling `player.arm_energy.gain(1, &"steampunk")` through `call_deferred`; each block calls it from its own "use" moment (catch, `launched`, enter). Per-element cooldown lives in the block's config (whole seconds).

### `scripts/kit/configs/<block>_config.gd` + `resources/kit/<block>/<preset>.tres` (config, CRUD)

**Analog:** `scripts/kit/configs/timed_motion_config.gd`, `resources/kit/timed_motion/clock_hand.tres`.

**Config class** (`timed_motion_config.gd:1-35`):
```gdscript
class_name TimedMotionConfig
extends Resource
enum Profile { SWEEP, TILT }
enum Timing { ALWAYS_ON, SWITCHED }
@export var profile: Profile = Profile.SWEEP
@export_group("Motion")
## Peak angular speed in rad/s; raise it for a faster swing ...
@export_range(0.1, 6.0, 0.1) var angular_speed: float = 1.0
```
Rules: every divisor/timer field has a strictly positive `@export_range` minimum (T-05.1-13, `test_kit_blocks.gd` `"positive"` list); new enum values are APPENDED (serialized ints); energy fields are `int` steps (D-34) with tick intervals in s, never "per second" amounts.

**Preset `.tres`** (`clock_hand.tres`): `script_class` header, one `ExtResource` to the config script, `[resource]` with `script = ExtResource("1_cfg")` then every field as plain values.

**Register in `tests/smoke/test_kit_blocks.gd` `BLOCKS`** (`:11-60`): one dictionary entry per block (`script`, `config_class`, `config_script`, `profiles`, `preset`, `scene`, `probe`, `positive`, `profile_presets`; optional `profile_enum`/`profile_field` as `WallSurface` does).

**F2 panel:** the kit section lists only `TYPE_FLOAT` + `PROPERTY_HINT_RANGE` (`tuning_panel.gd:169`); int step fields need the `TYPE_INT` branch added there.

### Request-API-only player influence (04.1 D-06, D-17)
**Source:** `scripts/kit/blocks/catch_launch.gd:196-206`, `mechanisms/bounce_pad.gd:62-69`, `mechanisms/force_field.gd:50-75`.

### Config duplication (D-12) and `reset()` (FallReset)
**Source:** `kit_block.gd:34-37` (`own_config`), `catch_launch.gd:52-55`. **Apply to:** all blocks. Runtime state on the node only; override `reset()` with `super.reset()`.

### KitBlock base hooks
**Source:** `kit_block.gd:20-30`: groups `mechanism` + `kit_block`, `MechanismLook.apply(self)` for STEAMPUNK/ENERGY in `NOTIFICATION_READY` (reaches the base even if a subclass overrides `_ready`). Nature gets its own look pass (`mechanism_look.gd` keyword-by-node-name pattern with preloaded `StandardMaterial3D` `.tres`).

### Whole-step energy (D-34..D-39)
**Source:** `arm_energy.gd` APIs. **Apply to:** every consumer. Pay with `try_spend(int, reason)`; refusal only through `refuse(reason, needed)` (the single emitter of `energy_refused`; arm flicker listens at `arm_energy_presentation.gd:74, 193`); income through `gain(int, source)`. No float energy, no "per second" energy amounts; time appears only as tick intervals. Dash hop stage 2/3 is the only silent fallback (`player_controller.gd:560`).

### Real-time presentation under slow motion
**Source:** `catch_launch.gd:_process` uses `TimeFx.unscaled(delta)`; `energy_hud.gd:67`. **Apply to:** HUD clock, Loader step timer, cue tweens, Loader-field ripple.

### EventBus facts carry values, never node references
**Source:** `autoload/event_bus.gd:50-75`. **Apply to:** any new signal (`player_hit`, `loader_released(steps)`, int `energy_*`): change signature and every handler atomically, add a row to `docs/CONVENTIONS.md` (`test_conventions.gd:78-83`).

### Typed GDScript, warnings are errors
**Apply to:** all new code: static types on every var/param/return, `@export_range` with positive minimum for divisors, `## ` doc comments on every export, no dangling `class_name` references when deleting (references first, files later, RESEARCH 2.3).
