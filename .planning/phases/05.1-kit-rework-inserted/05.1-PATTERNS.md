## Pattern Assignments

### `scripts/kit/kit_block.gd` (base block, event-driven)

**Analog:** `scripts/mechanisms/mechanism.gd` (46 lines, read in full). `KitBlock` keeps the group `mechanism` and the `NOTIFICATION_READY` look hook so `FallReset.reset` and `MechanismLook` keep working (RESEARCH Pattern 4).

**Core pattern** (mechanism.gd l.14-24):
```gdscript
func _ready() -> void:
	add_to_group(&"mechanism")
	if source != null:
		source.active_changed.connect(set_signal)
		set_signal(source.is_active)

func _notification(what: int) -> void:
	if what == NOTIFICATION_READY:
		MechanismLook.apply(self)
```
**Reset contract** (l.37-39): `reset()` re-reads the source without firing `_on_signal`. Subclasses rebuild look from state after `super.reset()`.

**New on KitBlock (D-16):** plain exported data for the coupling test.
```gdscript
enum Layer { STEAMPUNK, ENERGY, NATURE }
enum EnergyRelation { FREE, COSTS, AMPLIFIED }
@export var layer: Layer = Layer.STEAMPUNK
@export var energy_relation: EnergyRelation = EnergyRelation.FREE
```
Note: `Receiver` takes over `source` and `Behaviour` (D-13); `KitBlock` must not keep a `source` field. Blocks that need switching get a child `Receiver` and read `receiver.is_on()`.

**Analog:** `scripts/player/movement_config.gd` (header l.1-10, group/range/doc-comment style l.12-30).

```gdscript
class_name MovementConfig
```

Copy: `class_name XConfig extends Resource`, `@export_group`, one `##` doc line per field that says what raising it does, `@export_range` with strictly positive minimum on every divisor field (T-02-02). Variants as ONE enum per block (D-11), e.g. `RESEARCH` Pattern 1:
```gdscript

@export var profile: Profile = Profile.FREE_AIM
@export_range(0.05, 1.0, 0.01) var fixed_hold: float = 0.2
```
