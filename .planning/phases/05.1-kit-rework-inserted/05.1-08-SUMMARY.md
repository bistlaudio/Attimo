# Phase 05.1 Plan 08: Energy step clock Summary

The arm energy is now a clock of 12 whole steps. Every ability pays steps, every unpaid attempt refuses exactly once, income is a passive +1 per 10 s (or +1 per 5 s while R is held standing still, never stacking) plus whole-step capsules and machines, and moving never charges.

## Tasks

1. Step-clock tests first (expected RED, parse errors against the old API), commit 1d96ce6.
2. ArmEnergy int clock, MovementConfig step fields, EventBus ints, all gameplay consumers, CONVENTIONS rows, commit 4bb3429. The four energy tests pass.
3. F2 and metrics take ints, Energy_Track removed, all call sites flipped, metrics and gym regenerated, commit 6903576.

## Key results

- `ArmEnergy`: `MAX_STEPS` 12, `CORE_STEPS` 3, `CHECKPOINT_STEPS` 3, `value: int`, `tick(delta, state, still)`, `tick_progress()`; `drain`, `report_spent`, `passive_rate` removed.
- Costs: dash and air dash 1, hop stage 2 and 3 +1 each (silent fallback to stage 1), wall jump 1, wall run 2 on entry then 1 per 1 s (unpaid tick drops into Fall silently).
- Refusals: `dash`, `air_dash`, `wall_run` (once per wall contact), `wall_jump` (consumes the buffered press) each emit one `energy_refused`.
- `EnergySource.take_step()` and a step-timed Extractor (capsule 3 x 0.15 s, machine 5 x 0.4 s).
- F2 panel shows int fields (slider step 1, `_apply` stores `roundi`); the metrics snapshot guard loops `TYPE_INT`.
- MOVEMENT-METRICS: only the Energy rows, the config snapshot rows of the changed energy fields and the latency rows (measurement noise) changed; every Ground, Jump, Air, Long jump, Loader, Timing, Floor and Grid row is identical. The measurement `_begin` now duplicates the config with an out-of-reach passive interval and `reset_to(5)`, and `_top_up` restores 5 steps before each dash or hop.
