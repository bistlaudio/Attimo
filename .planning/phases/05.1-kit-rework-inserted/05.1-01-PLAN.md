Use the process-group form written into every plan's automated tool lines, because run.sh starts Godot as a child process and a plain `alarm; exec` would only kill bash and orphan Godot: the wrapper forks, puts the child in its own process group, and on the 600 s alarm sends TERM to the whole group and exits 124 (verified: no orphan left, exit code passes through otherwise). Plain `bash attimo/tests/run.sh --tool ...` lines in later plans mean this bounded form. On a non-zero exit, restore a half-written scene with `git checkout -- attimo/scenes/test/movement_gym.tscn`, read the Godot log for the SCRIPT ERROR and fix it.
