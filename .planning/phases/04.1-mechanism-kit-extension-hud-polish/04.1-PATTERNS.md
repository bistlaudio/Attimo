## Pattern Assignments

### Area3D mechanisms (force field, wind, low-g, geyser, ring, slingshot, bounce)

**Analog:** `scripts/mechanisms/steam_nozzle.gd`

Setup (lines 28-40): Volume mask PLAYER only, `super._ready()` last.
```gdscript
@onready var _volume: Area3D = $Volume
func _ready() -> void:
	_volume.collision_layer = 0
	_volume.collision_mask = PhysicsLayers.PLAYER
	_volume.body_entered.connect(_on_body_entered)
	super._ready()
```
Continuous push (lines 42-54): loop overlaps, cast to PlayerController, call request API, never write velocity.
```gdscript
for body: Node3D in _volume.get_overlapping_bodies():
	var player: PlayerController = body as PlayerController
	if player != null:
		player.push_toward(push_direction(), speed, accel)
```
One-shot (lines 91-99): `_armed` + cooldown guard, then `player.call_deferred(&"launch_along", dir, speed)`.
`is_active()` = `behaviour == REVERSE_ON_SIGNAL or signal_on`; `reset()` restores armed/cooldown. Base: `scripts/mechanisms/mechanism.gd` (`source`, `set_signal`, `_on_signal`, `reset`, group `mechanism`). Header doc comment style: class doc `##` stating the "never writes the player's velocity" rule. Bounce pad: connect `EventBus.landed(position, impact_speed)` (Research Pattern 2). Piston/pendulum: `call_deferred(&"knock_back", impulse)`.

### PlayerController request APIs

**Analog:** `scripts/player/player_controller.gd` lines 278-316.
```gdscript
func push_toward(direction: Vector3, target_speed: float, accel: float) -> void:
	if not direction.is_finite() or not is_finite(target_speed) or not is_finite(accel):
		return
	...
	_push_directions.append(direction.normalized()) ...
func knock_back(impulse: Vector3) -> void:
	if not impulse.is_finite(): return
	air_speed_cap = maxf(air_speed_cap, horizontal_speed())
	_enter_fall()
	EventBus.knocked_back.emit(global_position, impulse)
```
New APIs (`request_gravity_scale`, `refill_air_dash`, `boost_along`, `lock_air_control`, `capture_along`, `launch_along(..., keep_sideways)`) copy this: `is_finite` guard, set caps, `EventBus` fact, `_enter_fall()`/transition. Wall bookkeeping goes in `_post_move` before the clamp at about lines 473-478 (see Research).

## Shared Patterns

- **No velocity writes from mechanisms (D-06):** only `push_toward`, `launch_along`, `knock_back` and new request methods; `call_deferred` for one-shots inside physics callbacks.
- **Typed GDScript:** `untyped_declaration=2` is an error: annotate every `var` and loop variable (`for body: Node3D in ...`, `for i: int in n`).
- **Mesh sanction:** gym `MeshInstance3D`s must live under scenes in `res://scenes/proto/` or `res://scenes/mechanisms/` (test_movement_gym).
- **Glow materials:** only Interactables use `glow_idle/aim/target`; always-on glow uses new `glow_energy/glow_off`. Keep node `GlowLens` as a `MeshInstance3D` with `material_override` (test_glow_stages).
- **Animation map:** new FSM states must be named in `docs/ANIMATION-MAP.md` (test_animation_map); `MannequinAnimator.STATE_TO_ANIM` falls back to Locomotion.
- **Tests:** `extends RefCounted`, `run(tree, check)`, Fixtures helpers, deterministic tick waits, no Tweens in mechanisms (use `_physics_process` accumulators).
