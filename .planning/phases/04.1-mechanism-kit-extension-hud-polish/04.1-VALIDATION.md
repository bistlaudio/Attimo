## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Project-own headless smoke runner `attimo/tests/run_smoke.gd` (auto-discovers `res://tests/smoke/test_*.gd`) |
| **Config file** | none (`attimo/tests/run.sh` wraps version gate, repo checks, `--import`, run, log grep) |
| **Quick run command** | `bash attimo/tests/run.sh <filter[,filter]>` |
| **Full suite command** | `bash attimo/tests/run.sh` |
| **Gym regeneration** | `bash attimo/tests/run.sh --tool res://tools/build_movement_gym.gd` |
| **Estimated runtime** | ~60-240 seconds (first `--import` can exceed 3 min) |

## Sampling Rate

- **After every task commit:** Run `bash attimo/tests/run.sh <the task's filters>`
- **After every plan wave:** Run `bash attimo/tests/run.sh`
- **Before `/gsd-verify-work`:** Full suite green plus a freshly regenerated, committed `movement_gym.tscn`
- **Max feedback latency:** ~240 seconds
