## Pattern Assignments

### `scripts/player/loader_math.gd` (utility, transform)

**Analog:** itself. Keep `_pos` and `discharge_velocity`, `launch_apex`/`launch_reach` guard style; delete `discharge_speed_uncapped`, `discharge_speed`, `overflow`, `flight_distance`, `straight_reach` (`:16-48`).

**Guard style to copy** (`loader_math.gd:10-12`, `:50-54`):
```gdscript
static func _pos(value: float) -> float:
	return maxf(value, 0.0) if is_finite(value) else 0.0

static func discharge_velocity(direction: Vector3, speed: float) -> Vector3:
	if not direction.is_finite() or not is_finite(speed) or direction.length_squared() < 0.000001:
		return Vector3.ZERO
	return direction.normalized() * speed
```
**New functions (same file, same guard rule: non-finite = 0):** `stage_speed(stage, speeds)`, `shot_time(stage, times)`, `exit_speed(own, stage_speed, cap) = minf(maxf(_pos(own), _pos(stage_speed)), cap)`, `shot_reach(...)`/`shot_apex(...)` stepping in the same order as `_integrate` (half-step gravity before and after, rise 34 / fall 44.2, dt 1/60). Room builder, metrics tool and tests all call these (single source, RESEARCH "Don't Hand-Roll").
