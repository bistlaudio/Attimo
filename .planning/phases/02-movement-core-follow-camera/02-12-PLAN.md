## Phase Goal

This plan makes MOVE-10's "all movement values are live-tunable in one resource" concrete in game: an F2 panel edits the live MovementConfig and the camera settings, so the gym sign-off (02-14) can tune by feel. Split from the camera-controls plan (02-10) to keep both plans small.

## Flagged Assumptions (non-blocking; the developer may veto at review)

- **A15** The panel's "Save movement config" button writes the shared MovementConfig back to its res:// file only when running from the editor (OS.has_feature("editor")); otherwise it is disabled. It never writes to user://.
- **A10** Sensitivity is a multiplier 0.1-3.0 (default 1.0); invert-Y defaults to off (02-10). The slider range comes from the CameraSettings constants, not literals.
- **A41 (from 02-10, user decision in plan revision 2)** Auto-follow mode auto (default: follow only after joypad input) / on / off. The panel shows it as an OptionButton labelled "Auto-follow" with the items built from CameraSettings.AUTO_FOLLOW_MODES (shown capitalised as Auto, On, Off), so the selector and the settings class can never disagree.
