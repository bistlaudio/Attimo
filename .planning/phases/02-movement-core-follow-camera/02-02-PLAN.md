## Phase Goal

**As a** player, **I want to** run, sprint, jump, double jump and dash with a smooth camera, **so that** moving feels fluid and fast.

This plan fixes the names that the rest of the phase codes against (actions, facts, folders, rules) and records the camera decision (D-18, D-14) in the project docs that still say otherwise. It runs in parallel with the tracer: it touches none of the tracer's files. The planning docs CONTEXT assigns to the planner (REQUIREMENTS.md CAM-01, ROADMAP.md success criterion 1 and Notes, the STATE.md camera blocker) were already edited at planning time, so this plan only owns CLAUDE.md and STACK.md.

</objective>
