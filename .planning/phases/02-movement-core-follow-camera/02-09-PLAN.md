## Phase Goal

**As a** player, **I want to** run, sprint, jump, double jump and dash with a smooth camera, **so that** moving feels fluid and fast.

This plan adds the speed verbs: hold-to-sprint, the real ground dash, one air dash per airtime, the cooldown, the exit carry, and the dash-to-jump hand-off that 02-11 turns into the long jump.

<objective>
Add the Sprint state (D-03), replace the Phase 1 timer dash with a velocity-override dash for ground and air (D-10, D-11, D-12) gated by cooldown and the air-dash flag, combine it with the double jump in any order (D-08), and prove distance, cooldown, altitude hold, combos, exit carry and no tunnelling in test_dash (renamed from test_dash_fact and repaired by 02-04; this plan extends it).

Purpose: MOVE-02, MOVE-06 and MOVE-07 (air dash, dash into jump).
Output: sprint.gd, rewritten dash.gd, controller dash gating, Sprint node, extended test_ground_movement, extended test_dash.
</objective>

## Flagged Assumptions (non-blocking; the developer may veto at review)

- **A5** Dash stays on Q and Left Ctrl until the gym sign-off (02-14).
- **A13** dash_exit_cap starts at 12 m/s. Until 02-11, a jump during a ground dash is a normal Jump; 02-11 makes it the long jump (D-06). The test here only pins "leaves Dash into a rising jump with at least run speed", so it stays valid after 02-11.
- **A26** Sprint uses ground_accel up to run speed and sprint_accel above it, so starting a sprint from standstill is never slower than starting a run. Idle keeps handing over to Run; Run enters Sprint on its next tick when sprint is held, and because Run and Sprint accelerate identically below run speed the one Run tick changes nothing in the speed curve (this keeps idle.gd out of this plan).
- **A27** A jump pressed during an air dash cancels it into the double jump when that is still available (D-08 "air dash -> double jump"); otherwise the press follows the normal buffer rules after the dash.
