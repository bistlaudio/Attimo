## Phase Goal

**As a** player, **I want to** run, sprint, jump, double jump and dash with a smooth camera, **so that** moving feels fluid and fast.

This plan adds the measuring instruments of success criterion 5: a latency probe for FEEL-06 and a live metrics overlay for D-21, both pure listeners on the fact bus.

<objective>
Build LatencyProbe (stamps jump/dash input events, measures the time to the matching fact, records the first drawn frame after it) and MetricsOverlay (F4 overlay with per-airtime jump height and distance, dash distance, chain stage, latency summary and an F6 tick-rate cycle), prove the latency at 60 and 120 TPS headless, and put the overlay into the test scene.

Purpose: FEEL-06 needs a measured number, and tuning in the gym (D-21) needs live numbers next to the gym markings.
Output: latency_probe.gd, metrics_overlay.gd + .tscn, test_latency, test_metrics_overlay, overlay instance in test_scene.
</objective>

## Flagged Assumptions (non-blocking; the developer may veto at review)

- **A24 (RESEARCH A5)** Expected software latency is about half a tick on average and about one tick worst case (roughly 8 / 17 ms at 60 TPS, 4 / 8 ms at 120 TPS). The number excludes display, compositor and USB latency; 02-13 writes this caveat into MOVEMENT-METRICS.md (D-22). Because the prediction is far below 66 ms, the 66 ms target is asserted, not just reported; a failure is a real FEEL-06 defect to fix, never a threshold to relax. Real end-to-end hardware latency stays a flagged human item in the 02-14 sign-off.
- **A25** `RenderingServer.frame_post_draw` may never fire headless; the frame figure is shown when available and is not asserted.
- **A9** debug_metrics = F4 / 9 and debug_tick_rate = F6 / 0 (02-02).
- **A39 (from 02-01, Debug Draw 3D)** The overlay is built from Labels in a CanvasLayer; Debug Draw 3D (CLAUDE.md addon list) is not adopted in Phase 2 and no res://addons folder is added. Revisit it when aim-assist cones or wall-run raycasts need visual tuning (Phase 3 aim mode, v2 wall-run). Logged in STATE.md decisions.
