# Animation map (MOVE-11)

Which movement verb is shown by which Mannequin clip. Guarded by `attimo/tests/smoke/test_animation_map.gd`: the test fails when a state node of `player.tscn`, a clip referenced by `mannequin_tree.tres` or any clip of the library is missing from this file (the map is the whitelist of the library), or when a referenced clip is missing from the library.

## Rules

- The source of truth is the movement FSM (`StateMachine` under `Player`). `MannequinAnimator` only presents it: it travels the animation state machine on the same call as the FSM state change and never decides movement state.
- Clip sources: KayKit `Rig_Medium` clips plus retargeted external clips (Mixamo `Running_Slide`, quick 261118-qbt; the Quaternius UAL clips with the `UAL_` prefix, quick 261118-qi3), all baked into one library `res://assets/animations/rig_medium/rig_medium_library.res` (DEV-04, a deviation from FOUND-05 "kit clips only"; see "External clips" and "Retarget quality rule"), plus cuts, blends, playback speed and procedural rotation. There are no hand-keyed clips in this phase.
- The animation root is an `AnimationNodeBlendTree` generated by `tools/build_mannequin_tree.gd` into `scenes/player/mannequin_tree.tres`: StateMachine -> TimeScale -> IdleBreak -> Land (input 1 `LandPick`) -> Aim -> output. The Aim layer's input 1 is the `Shoot` OneShot (input 0 `AimMachine` with `Enter`, `Hold`, `Exit`; input 1 `ShootClip`). Never edit the `.tres` by hand.
- Lean and pirouette are not clips. `ProceduralPose` writes them as code rotation on the `Mannequin` child of `VisualRoot` (DEV-01); see `docs/CONVENTIONS.md`.
- Aim mode (hold `aim`) adds an upper-body layer and a different locomotion blend; it never changes the FSM states. There is no dash while aiming (quick 261120-dik): the aimed dash nodes `DashLeft`, `DashRight` and `DashBack` are dormant.
- Dash crossfades (quick 261120-dik): into a dash clip `dash_in_blend` 0.06 s from `Locomotion` and `dash_in_blend_air` 0.08 s from `Jump`, `Jump2`, `LongJump` or `Fall`; out of a dash clip `dash_out_blend` 0.15 s. They are `MovementConfig` rows that `MannequinAnimator.apply_blend` writes to the generated tree's edge just before each travel (live-tunable); every other edge keeps 0.1 s and the `Slide` edges their own. The `Land` overlay (fade out 0.1 s) and the idle break (fade out 0.1 s) fade out and never cut. The travel itself still happens on the state-change frame.

## Clip variants

`VariantPicker` (`attimo/scripts/player/variant_picker.gd`, RefCounted, no engine nodes or globals, so the boss and the mechanisms can reuse it) is the one rule for presentation variants: `pick(pool, options)` picks at random and never returns the last pick of that pool again while two or more options exist; `pick_first(pool, branches)` picks from the first branch whose condition holds (the landing kind: roll, hard, soft); `delay(min, max)` rolls a finite delay (the idle break). Pools are filtered to the clips the library has, so a dropped clip vanishes. Every variant changes on the same frame as its state and never delays input.

The retarget path is `tools/clip_retargeter.gd`: a `BoneMap` on `SkeletonProfileHumanoid` is the pivot vocabulary, one map per source family (`mixamo`, `ual` for the Quaternius Universal Animation Library, `rig_medium` for the round-trip test). Rotations are transferred through character-space bone directions, so a T-pose and an A-pose source both work. The hips stay in place (`pin_horizontal`, the dash moves the body in code); the hips height follows the source's floor contact, and no foot or toes joint sinks more than 8 % of the hips height below its rest height. `test_retarget` guards the maps, a round trip, the limb direction parity and the slide depth.

Adding an external clip:

1. Put the raw file into the reference library outside the project (`KayKit/Mixamo/` for Mixamo, the UAL pack under `KayKit/Universal Animation Library[Standard]/`). FBX files never go inside `attimo/`.
2. Add a row to `ROWS` in `tools/conform_external_clip.gd` (raw path, output `.scn`, clip name) and run it: `bash attimo/tests/run.sh --tool res://tools/conform_external_clip.gd`.
3. Check that the source family map in `tools/clip_retargeter.gd` knows every bone (`mixamo` and `ual` are ready; a new family is one more const map).
4. Add a row to `RETARGETED` in `tools/build_animation_library.gd` (clip, conformed scene, family, loop, `pin_horizontal`) and run it. It prints the hips height curve of the new clip.
5. Add the `.scn` to the whitelist of `test_asset_hygiene`, the clip to `test_animation_library`, and a row to the verb table and to this section; add a state-machine node in `tools/build_mannequin_tree.gd` if a verb plays it, and run that tool.

## Retarget quality rule

Every retargeted UAL clip must pass the headless bone-sanity gate `attimo/tests/smoke/test_retarget_sanity.gd` (sampled every 1/30 s through `clip_retargeter.gd` `sample_globals` on the Mannequin skeleton):

- S1: every track path starts with `Rig_Medium/Skeleton3D:` and names a Mannequin bone.
- S2: no bone-to-parent distance leaves its rest length by more than 2 % or 1 cm (no stretched limbs).
- S3: the closest approach of `hand.l`, `hand.r`, `lowerarm.l`, `lowerarm.r` to the head and to the hips-to-chest segment is no smaller than the same minimum over the native library clips minus 0.05 m (no magic radius; measured native minimum 0.316 m).
- S4: upright clips (all except roll and death) keep head above chest above hips, hips height 0.6 to 1.2 times rest.
- S5: upright clips keep both feet above the native minimum foot height minus 0.05 m.
- S6: loop clips keep the hips within 0.15 m of rest horizontally and their first and last pose within 10 degrees.
- S7: every clip keeps hips, chest and head above the floor minus 0.05 m (the retarget floor rule only knows the feet).

A self-check feeds the clearance check a hand inside the head and expects a failure. Drop rule: a clip that fails (clips through head, body or floor, slides badly, or fails the developer's presentation review, for example the wrong hand) is dropped: its conform row, `RETARGETED` row, `.scn` and whitelist entry are removed, it is added to `UAL_DROPPED` in `tools/build_animation_library.gd` with the failing check as the reason, and the tools are re-run. Its KayKit fallback stays. `tools/build_mannequin_tree.gd` `FALLBACK` maps every wired UAL clip to the KayKit clip its node plays when the library lacks it (and prints `TREE: fallback`): the four Spell clips -> `Ranged_1H_Aiming`, `UAL_Sprint_Loop` -> `Running_A`, `UAL_Jump_Land` and `UAL_Roll` -> `Jump_Land`, `UAL_Idle_Loop` -> `Idle_A`.

Dropped clips:

- `UAL_Push_Loop`: S3 arm clearance 0.241 m (limit 0.266 m). Reserved for Phase 5 only, no fallback; re-check when Phase 5 wires a push.
- `UAL_Jump_Land`: S4 hips drop to 41 % of rest (limit 60 %). The hard landing builds from `Jump_Land`.
- `UAL_Interact`: S3 arm clearance 0.263 m (limit 0.266 m). The KayKit `Interact` stays the only interact clip.
- `UAL_Spell_Simple_Enter`, `UAL_Spell_Simple_Idle_Loop`, `UAL_Spell_Simple_Shoot`, `UAL_Spell_Simple_Exit`: presentation review (developer gym feedback "the aim pose looks weird", then a headless probe). They pass S1 to S7, but the UAL source is a left-handed cast (`hand_l` leads 0.72 m in front of `spine_03`) and twists the chest 57 degrees away from the right arm (`Ranged_1H_Aiming`: 36 degrees towards it). The prosthetic is the right hand and `AimPoseModifier` points the right arm, so the layer fought the solver. Mirroring would need a retargeter change. All four nodes play the `Ranged_1H_Aiming` fallback.
- `UAL_Jump_Start` (tried as the Jump 2 take): S4 hips drop to 49 % of rest (limit 60 %). Jump 2 stays on `Jump_Full_Short`.
- `UAL_Roll`: S7 the head sinks 0.27 m and the hips 0.09 m below the floor at 0.70 to 0.80 s (the inverted body of the roll is pushed through the floor by the feet-only floor rule). The roll landing builds from `Jump_Land`.

## Adding a verb

A new verb lands only together with a kit clip or a composition row in this table, in the same change as its state. Add the state name, the animation node and the clip name (backticked) to the table above; `test_animation_map` fails otherwise.
